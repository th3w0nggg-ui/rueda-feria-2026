# SpectroPark Dynamics · Grupo 8

Sitio web con dos proyectos:

1. **Rueda de Chicago**: rueda mecánica movida por un motor eléctrico.
2. **BioWheel**: rueda inteligente con sensor RGB y Arduino para analizar el color de las hojas (Colegio Las Américas, Feria Científica 2026).
