ARQUITECTURA POO

La lógica detrás del movimiento.

El motor gira y la rueda calcula su ángulo. Es una arquitectura educativa de referencia.

class MotorElectricoclass RuedaChicago
class MotorElectrico:
    def __init__(self):
        self.encendido = False
        self.rpm = 0

    def encender(self, rpm):
        self.encendido = True
        self.rpm = rpm

    def apagar(self):
        self.encendido = False
        self.rpm = 0


class RuedaChicago:
    def __init__(self, motor, cabinas=8):
        self.motor = motor
        self.cabinas = cabinas
        self.angulo = 0

    def girar(self, segundos):
        grados = self.motor.rpm * 360 / 60 * segundos
        self.angulo = (self.angulo + grados) % 360
        return self.angulo


motor = MotorElectrico()
rueda = RuedaChicago(motor)
motor.encender(rpm=4)
print(rueda.girar(segundos=2))  # 48.0

BioWheel

Rueda inteligente para detectar y analizar el color de las hojas. Una maqueta de rueda de la fortuna con sensor RGB y Arduino que convierte el color reflejado por una hoja en datos. Integra Física, Química, Biología, Tecnología y Programación.

PROYECTO

Planteamiento y objetivos

LED

La rueda

Una maqueta de rueda de la fortuna iluminada: la parte mecánica y visual del proyecto.

RGB

El sensor

Un sensor de color y Arduino miden y controlan: registran el color que refleja la hoja.

DATOS

La respuesta

El resultado se representa con luces o un indicador de la maqueta.

PROBLEMA

El color de una hoja varía según su estado, edad, condiciones ambientales y proporción de pigmentos. La observación visual es subjetiva y depende de la iluminación y del observador.

PREGUNTA DE INVESTIGACIÓN

¿Cómo puede un sistema con sensor de color y Arduino detectar diferencias en el color de las hojas y representarlas mediante una maqueta interactiva?

HIPÓTESIS

Si se utiliza un sensor de color bajo condiciones de iluminación controladas, entonces será posible obtener valores RGB para distintas hojas, utilizando principios de Física, Química, Biología y Programación.

JUSTIFICACIÓN

Es una demostración educativa: aplica la tecnología a una pregunta biológica y transforma una característica visual en una medición reproducible bajo condiciones controladas.

Objetivo general

Diseñar y construir una maqueta funcional que combine una rueda de la fortuna iluminada con un sistema de detección de colores de hojas, utilizando principios de Física, Química, Biología y Programación.

Objetivos específicos

  • Construir una rueda de la fortuna funcional con iluminación LED.
  • Integrar un sensor RGB y un microcontrolador Arduino.
  • Medir y registrar los componentes rojo, verde y azul de la luz reflejada por las hojas.
  • Comparar experimentalmente hojas de diferentes tonalidades.
  • Explicar la relación entre el color observado, los pigmentos vegetales y la luz.
  • Programar una respuesta visual mediante LEDs o una pantalla.
  • Presentar los resultados mediante tablas, gráficas y fotografías.
MARCO TEÓRICO

Cuatro disciplinas

BIO

Biología: color de las hojas

Las hojas contienen pigmentos que absorben ciertas longitudes de onda y reflejan otras. La clorofila es el pigmento principal asociado al verde y participa en la fotosíntesis. Los carotenoides y las antocianinas pueden contribuir a colores amarillos, anaranjados, rojizos o morados.

QUÍ

Química: pigmentos y luz

Los pigmentos son sustancias que interactúan con la radiación visible. Una superficie se ve de cierto color porque refleja parte de la luz y absorbe otra. El sensor no ve como una persona: mide la respuesta de la luz en distintos componentes de color.

FÍS

Física: luz, color y electricidad

Un sensor RGB separa la respuesta en rojo (R), verde (G) y azul (B). La electrónica convierte la señal en datos para el microcontrolador. El giro de la rueda se explica con rotación, fuerza, energía mecánica y transferencia de energía eléctrica.

Programación y sensores

Los sensores de color para Arduino entregan información asociada a los componentes RGB. Se consideran los modelos TCS3200/TCS230 o TCS34725, según disponibilidad. El programa lee los valores, los compara con los rangos de la calibración y activa una respuesta visual.

Para comparar de forma confiable se mantienen constantes la distancia entre sensor y hoja, la iluminación, el fondo y la posición de la muestra, y se calibra con superficies de referencia.

METODOLOGÍA

Cómo se mide

Se construye la rueda, se instalan los componentes electrónicos y se fija el sensor en una posición. El Arduino registra los valores RGB de hojas de diferentes tonalidades, con al menos tres lecturas por muestra y un promedio para disminuir pequeñas variaciones.

Materiales de construcción

  • Arduino Uno o placa compatible
  • Sensor de color RGB (TCS3200/TCS230 o TCS34725)
  • LEDs o tira LED de bajo voltaje
  • Resistencias apropiadas para los LEDs
  • Protoboard y cables jumper
  • Fuente de alimentación o power bank adecuado
  • Motorreductor pequeño y controlador (si la rueda se automatiza)
  • Eje y soportes para la rueda
  • Computadora con Arduino IDE
  • Hojas reales para las pruebas
  • Regla, cinta, tijeras y materiales de decoración
  • Opcional: pantalla LCD/OLED

Procedimiento

  1. Construir la rueda y comprobar que gire de forma estable antes de instalar los LEDs.
  2. Montar el sensor de color en una posición fija.
  3. Conectar el sensor al Arduino según el esquema del modelo elegido.
  4. Programar una lectura básica y comprobar que los datos cambien con distintos colores.
  5. Calibrar con una referencia clara y una oscura, si el sensor lo requiere.
  6. Seleccionar varias hojas y registrar al menos tres lecturas por muestra.
  7. Calcular un promedio por muestra.
  8. Programar una clasificación experimental por tonalidad, sin presentarla como diagnóstico de salud de la planta.
  9. Conectar los LEDs de la rueda para que respondan a la categoría detectada.
  10. Registrar fotografías, observaciones y resultados.

FAQ

Preguntas frecuentes

¿Qué mueve la Rueda de Chicago?+

Un motor eléctrico hace girar la rueda.

¿Dónde está el sensor RGB?+

En BioWheel, el proyecto que mide el color de las hojas con un sensor RGB y Arduino. La Rueda de Chicago no usa sensores de color.

¿Por qué utilizar programación orientada a objetos?+

Permite dividir el sistema en componentes independientes, como el motor y la rueda. Esto facilita probar, mantener y ampliar el proyecto.

¿Dónde se puede aplicar este concepto?+

La base de estructura más motor se puede adaptar a atracciones, demostraciones educativas y otros sistemas mecánicos automatizados.

¿Qué diferencia hay entre los dos proyectos?+

La Rueda de Chicago es una rueda mecánica movida por un motor eléctrico. BioWheel usa un sensor RGB y Arduino para medir el color de hojas reales y responder con luces; es el proyecto de la Feria Científica del Colegio Las Américas.
